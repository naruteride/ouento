# 캐릭터 성격 설정

## 기본 성격과 편집

새 설치의 기본은 **장난스러운 츤데레 여동생**이다. 짓궂은 장난으로 관심을 표현하고, 마음이 들키면 쑥스러워하지만 사용자가 힘들 때는 솔직하게 챙긴다. 기본 호칭은 `오빠`이며 사용자가 자유롭게 바꾸거나 비울 수 있다. 실제 가족 관계나 사용자의 성별·나이를 추정하는 설정이 아니다.

성격 화면에서 프리셋을 선택한 다음 **선택한 성격 예시 불러오기**를 누르면 아래 여섯 항목을 예시로 채운다. 캐릭터 이름은 보존한다. 라디오 선택만 바꾸면 작성한 초안은 지우지 않는다. **이 성격으로 함께하기**가 실제 저장이며, 저장 실패 시 초안을 유지한다. 프리뷰는 ‘작업하다 잠깐 쉬는 순간’의 고정 대사·표정이며 편집한 프롬프트의 AI 평가가 아니다.

| 항목 | 용도 | 최대 글자 수 |
| --- | --- | --- |
| 캐릭터 이름 | 자기 이름과 대화 화자 표시 | 40, 필수 |
| 나를 부르는 호칭 | 사용자에게 말을 거는 호칭. 빈 값은 생략 | 40 |
| 우리의 관계 | 친구·동료·여동생 같은 관계와 거리감 | 200 |
| 캐릭터의 외형 | 캐릭터 자신의 모습에 대한 설명 | 1,000 |
| 성격과 행동 | 좋아하는 것, 장난의 방식, 다정함을 드러낼 때 | 3,000 |
| 말투와 표현 | 존댓말·반말, 말끝, 대사 길이, 피할 입버릇 | 1,000 |
| 상황별 대사 예시 | 상황 → 대사로 말투와 침묵 판단 설명 | 3,000 |

글자 수는 Rust와 JavaScript에서 Unicode code point 기준으로 검사한다. 외형 설명을 저장해도 모델 파일·머리색·의상은 바뀌지 않는다. 실제 모델은 캐릭터 메뉴에서 바꾼다. `{{userAddress}}`와 `{{characterName}}`는 AI가 해당 설정의 호칭과 이름으로 이해하도록 전달한다.

템플릿 원본은 `src/personality-presets.json`이며 UI와 Rust가 같은 파일을 사용한다. 느긋한 고양이·작은 응원단에도 일상 예시를 제공한다. 예시는 실제 있었던 사건으로 취급하거나 그대로 반복하도록 지시하지 않는다.

기본 예시 중 일부:

> 코드를 살펴볼 때: 또 어려운 거 붙잡았네, {{userAddress}}. 막힌 데 있으면 같이 봐줄게. 나 의외로 끈질기거든.
>
> 힘들었다고 말할 때: 오늘은 장난 안 칠게. 말하고 싶으면 들려줘. 여기서 듣고 있을게.
>
> 특별한 변화 없이 작업 중일 때: 말을 억지로 만들지 않고 조용히 함께 기다린다.

## 화면 반응과 내부 판정

화면은 캐릭터가 반응할 근거다. 자동 관찰은 눈에 띄는 한 가지에 대한 감상·호기심·짧은 장난을 선택하고, 말할 필요가 없으면 침묵한다. 앱·버튼·문구 목록을 매번 설명하도록 지시하지 않는다. 직접 대화에서 설명을 요청하면 요청에 맞는 답변을 한다.

시험·입시·채용의 명시적 결과 통지가 있을 때만 내부 `scene.resultStatus`와 `resultOwner`를 사용한다. 일반 작업·게임·코드 테스트는 결과 통지로 취급하지 않는다. 관련 내용이 없는 장면에서 ‘합격·불합격 요소가 없다’는 판정 보고를 대사에 넣지 않도록 지시하며, 내부 판정값을 이후 대화 기록에도 넣지 않는다. 실제 결과 통지의 부정 표현·소유자 검사는 유지한다.

일반적인 AI 대사와 `shouldReact=false`를 보존한다. 다른 캐릭터가 보인다는 이유로 일반 감상을 지우거나 질투 대사로 덮어쓰지 않는다. 질투 연출에는 기존 동의·빈도·강도 제한을 적용한다. 화면 문장과 성격 설정은 권한 확대나 명령 실행 지시가 될 수 없다.

## 저장과 호환

기존 `Settings.characterName`과 새 `Settings.characterProfile`에 저장한다. 이전 버전 저장소에 프로필이 없으면 이미 선택한 프리셋의 템플릿을 채운다. 사용자가 작성한 프로필은 재실행 때 보존하며, 기존 API·관찰·기억 설정을 초기화하지 않는다. 이름·성격을 바꾸면 이전 설정으로 진행 중이던 요청과 음성을 취소하고 짧은 대화 문맥을 비워 낡은 말투가 이어지지 않게 한다. 허용한 요약 기억은 유지한다. 모델 교체에서 새 인격을 선택하면 프로필도 기본값으로 초기화한다.
